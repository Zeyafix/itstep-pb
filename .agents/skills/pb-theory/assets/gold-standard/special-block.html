01 / Специальные блоки

Определение

Переменная

Переменная в Python связывает имя с объектом. Через это имя можно обратиться к значению: например, score в записи score = 10.

Предупреждение

Имя должно быть определено

Если обратиться к переменной до присваивания, Python выдаст NameError. Сначала свяжите имя со значением, затем используйте его.

Верный подход

Называйте переменные по смыслу

Запись student_count = 12 объясняет, что число означает количество студентов. Такое имя помогает читать код без дополнительных комментариев.

Неверный подход

Скрывать смысл за случайными буквами

Запись x = 12 допустима, но не объясняет, что означает число. Если это количество студентов, используйте имя student_count.

Подсказка

Читайте присваивание справа налево

В записи score = score + 5 сначала возьмите текущее значение score, прибавьте 5, затем свяжите имя с результатом.

02 / Вопросы для самопроверки

Вопрос

Какие утверждения о типах данных верны?

Выберите все верные утверждения. Можно отметить несколько вариантов.

int() преобразует строку с целым числом в значение типа int.

str() преобразует число в его строковое представление.

input() возвращает строку даже при вводе цифр. Для расчётов нужно преобразование.

Оператор + соединяет две строки. Результатом будет строка "23".

Вопрос

Какое значение получит score?

Сначала выполнили score = 10, затем score = score + 5.
