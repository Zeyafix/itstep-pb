01 / Код в секции

Присваивание связывает имя с результатом вычисления. В консоли показан результат запуска примера.

Присваивание 
score = 10
score = score + 5
print(score)
Консоль
15

02 / Код в специальном блоке

Верный подход

Называйте переменные по смыслу

По имени должно быть понятно, что хранит переменная.

Понятное имя 
student_count = 12
print(student_count)
Консоль
12
