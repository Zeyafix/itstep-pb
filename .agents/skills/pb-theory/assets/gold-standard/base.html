01 / Параграфы и код

Переменная помогает обратиться к значению по имени. Например, сохранить имя студента, стоимость покупки или количество попыток.

Знак = связывает имя слева со значением справа. Сначала Python вычисляет правую часть, затем присваивает результат переменной.

В записи score = 10 имя score связано с числом 10. После score = score + 5 по этому имени доступно число 15.

Регистр имеет значение. Имена name и Name различаются. Выберите одно написание и используйте его последовательно.

Рекомендации по оформлению кода собраны в PEP 8.

02 / Маркированный и нумерованный списки

Что стоит помнить о переменных:

  • Имя объясняет назначение значения: student_count понятнее, чем x.
  • Для имён из нескольких слов используйте строчные буквы и подчёркивания.
  • Перед первым обращением к переменной присвойте ей значение.

Как прочитать присваивание score = score + 5:

  1. Возьмите текущее значение score.
  2. Прибавьте к нему 5.
  3. Свяжите имя score с результатом.

03 / Таблица

Функция input() возвращает строку. Чтобы использовать ввод в расчётах, преобразуйте его в число.

Функции преобразования типов и результаты
Функция Что делает Пример
int() Преобразует в целое число int("25") → 25
float() Преобразует в число с точкой float("2.5") → 2.5
str() Преобразует в строку str(25) → "25"
