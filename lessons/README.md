# Уроки

Здесь подключаются публичные Git-сабмодули уроков. Сейчас они ещё не добавлены.
Пример имени репозитория по схеме: `itstep-pb-lesson-01-02`.

Урок может содержать `notes.py`, HTML-теорию, папку `checks` с рубрикой,
эталонными решениями и тестами, а также публичные сабмодули `pa` и `hw`.
В репозиториях заданий размещаются файлы `01.md`, `02.md` и т. д., при
необходимости — `README.md`.

Подробности подключения: [репозитории и сабмодули](../docs/development/repositories.md).
