# Runtime HTML-материалов

Общие файлы находятся в обычной папке основного репозитория:

- `itstep-pb-assets/runtime/lesson-v1.css` — стили материалов и компонентов.
- `itstep-pb-assets/runtime/lesson-v1.js` — тема, навигация, копирование кода,
  подсветка Python и вопросы для самопроверки.

Для их изменения не нужен отдельный репозиторий ассетов.

## Подключение

Для HTML в корне урока `lessons/itstep-pb-lesson-01-02/` локальное подключение:

```html
<script src="../../itstep-pb-assets/runtime/lesson-v1.js"></script>
<link rel="stylesheet" href="../../itstep-pb-assets/runtime/lesson-v1.css">
```

Разместите эти элементы в `head`: скрипт перед стилями, без `async`, `defer`
и `type="module"`. Он выбирает тему до отрисовки и ждёт готовности DOM для
обработчиков. Для вложенных HTML скорректируйте относительный путь.
Локальное подключение предполагает, что урок находится в основном репозитории.

## Совместимость

Образцы разметки и инструкции находятся в [скиле `pb-theory`](../../.agents/skills/pb-theory/SKILL.md).
При расхождениях самостоятельных образцов и runtime используйте текущие
селекторы и атрибуты runtime. Python-коду нужен класс `language-python`,
текстовым вопросам — атрибуты `data-answer`, `data-hint` и `data-success`.
Ключ сохранения темы runtime — `pbv3-gold-standard-theme`; его имя унаследовано
и не меняется при переносе структуры репозитория.

## GitHub Pages

Публикация runtime через GitHub Pages пока не настроена. Публичный репозиторий
сам по себе не создаёт сайт. Адреса удалённых репозиториев ассетов не используйте
для новых HTML-файлов. После настройки Pages проверьте доступность обоих файлов
по HTTPS и укажите здесь подтверждённые URL для самостоятельных HTML-материалов.
