# Скилы репозитория

Локальные скилы находятся в `.agents/skills/`. Каждый скил содержит `SKILL.md`
с описанием назначения и инструкциями. Дополнительные файлы хранятся рядом с ним.

| Папка | Имя в `SKILL.md` | Назначение | Источник |
| --- | --- | --- | --- |
| `ze-commit` | `ze-commit` | Подготовка и создание Conventional Commits на английском языке. | `zedone/.agents/skills/ze-commit` |
| `ze-frontend-design` | `frontend-design` | Проектирование внешнего вида интерфейсов. | `zedone/.agents/skills/ze-frontend-design` |
| `ze-pr` | `ze-pr` | Подготовка, создание и обновление pull request на английском языке. | `zedone/.agents/skills/ze-pr` |
| `pb-theory` | `pb-theory` | Создание и редактирование теоретических HTML-материалов по комплектным образцам. | `pbv3/.agents/skills/pb-theory` |

Скилы перенесены вместе с дополнительными файлами: `agents/openai.yaml`,
справочными материалами и HTML-образцами там, где они есть. Инструкции
адаптированы под `itstep-pb` и учитывают `AGENTS.md` и текущую структуру репозиториев.
Источники в таблице указаны для справки. Исходные репозитории для работы
скилов не нужны, синхронизация с ними не настроена.

## Применение в текущем репозитории

- У папки `ze-frontend-design` имя скила в метаданных — `frontend-design`.
- `ze-commit` и `ze-pr` описывают результат для преподавателя, студента
  или разработчика. Основной репозиторий публичный; runtime хранится в нём
  обычными файлами. Уроки и задания имеют собственные публичные репозитории,
  группы — приватные. При изменении сабмодуля сначала отправляется его коммит,
  затем обновляется ссылка в родительском репозитории. Порядок работы описан
  в [инструкции по репозиториям](repositories.md).
- `frontend-design` учитывает аудиторию курса и сохраняет установленный
  дизайн теоретических материалов. Новый визуальный стиль уместен там,
  где задача оставляет свободу выбора или прямо требует переработки дизайна.
- `pb-theory` учитывает [текущий план курса](../current-roadmap.md), уровень
  студентов и формат встреч. Комплектные HTML-образцы показывают структуру
  и внешний вид компонентов. В материалах общие стили и обработчики
  подключаются из `itstep-pb-assets/runtime/lesson-v1.css` и `lesson-v1.js`.
  Inline-стили и скрипты образцов в материалы не копируются.
- При отличиях между самостоятельным образцом и runtime используется
  контракт текущего runtime: Python-коду нужен класс `language-python`,
  текстовым вопросам — свои `data-answer`, `data-hint` и `data-success`.
  Сохраняется ключ темы runtime; у самостоятельных образцов свой ключ
  `itstep-pb-gold-standard-theme`.
- Подтверждённые рабочие URL runtime в существующих материалах сохраняются.
  GitHub Pages пока не настроен. Для новых локальных страниц runtime
  подключается по относительному пути из основной папки репозитория.
  Подробности: [подключение runtime](runtime.md).

Работы студентов, оценки и история обучения остаются в приватных сабмодулях
групп. В основной репозиторий попадают публичные материалы, документация,
runtime и зашифрованный архив `docs/syllabus.rar` для преподавателей.

При изменении состава или назначения скилов обновляйте этот документ.
