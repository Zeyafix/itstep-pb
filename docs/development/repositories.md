# Репозитории и сабмодули

## Структура и доступ

Основной репозиторий [Zeyafix/itstep-pb](https://github.com/Zeyafix/itstep-pb)
публичный. Структура соответствует [схеме](../excalidraw-scheme/pb-scheme.png):

```text
itstep-pb/                              публичный репозиторий
├── AGENTS.md
├── itstep-pb-assets/                    обычная папка, не сабмодуль
│   └── runtime/
│       ├── lesson-v1.css
│       └── lesson-v1.js
├── lessons/
│   └── itstep-pb-lesson-01-02/          публичный сабмодуль урока (пример)
│       ├── notes.py
│       ├── *.html
│       ├── pa/                         публичный сабмодуль itstep-pb-pa-02
│       ├── hw/                         публичный сабмодуль itstep-pb-hw-02
│       └── checks/
│           ├── rubric.md
│           ├── pa/
│           │   ├── gold-standard/
│           │   └── tests/
│           └── hw/
│               ├── gold-standard/
│               └── tests/
├── groups/
│   └── GROUP_ID/                        приватный сабмодуль группы (пример)
│       └── 01-ФИО-HASH/
│           ├── summary.md
│           ├── assessments/
│           ├── hw/
│           └── pa/
└── docs/
    ├── teacher/
    ├── development/
    ├── current-roadmap.md
    ├── syllabus.rar                    зашифрованный архив для преподавателей
    └── excalidraw-scheme/
```

Имена урока и заданий в дереве иллюстрируют схему. Сейчас сабмодулей нет,
поэтому `.gitmodules` отсутствует. Его создаёт Git при подключении первого
сабмодуля. Отдельный репозиторий `Zeyafix/itstep-pb-assets` больше не используется:
runtime версионируется вместе с основным репозиторием.

Репозиторий урока публичный целиком, включая `checks`. Сабмодули `pa` и `hw`
содержат задания в файлах `01.md`, `02.md` и т. д., при необходимости — `README.md`.
Эталонные решения, тесты и рубрика хранятся в `checks` урока.

Содержимое приватного сабмодуля группы не попадает в историю основного репозитория.
При этом его путь, URL и хеш коммита видны в публичном репозитории. Не включайте
данные студентов в имена групп, URL и сообщения коммитов основного репозитория.
Обычные файлы внутри `groups/`, кроме его `README.md`, исключены через `.gitignore`;
это защищает от случайного добавления локальных работ студентов.

## Клонирование

Для основного репозитория и runtime доступ к приватным репозиториям не нужен:

```sh
git clone https://github.com/Zeyafix/itstep-pb.git
cd itstep-pb
```

После подключения уроков их можно загрузить вместе с вложенными `pa` и `hw`:

```sh
git submodule update --init --recursive -- lessons
```

Преподаватель с доступом к конкретной группе отдельно загружает её сабмодуль,
подставив реальный идентификатор вместо `GROUP_ID`:

```sh
git submodule update --init -- groups/GROUP_ID
```

Общее `git clone --recurse-submodules` пытается загрузить и приватные группы,
поэтому для публичного клонирования используйте выборочную загрузку уроков.

## Получение обновлений

Из корня основного репозитория, когда локальные изменения сохранены в коммитах:

```sh
git pull --ff-only
```

Эта команда обновляет и runtime. Если сабмодули уже подключены, затем выполните
соответствующие команды `git submodule update --init` из раздела выше.
Они получают именно коммиты, зафиксированные в основном репозитории.

## Изменение runtime

CSS и JavaScript меняются в основном репозитории без отдельного коммита ассетов:

```sh
git add itstep-pb-assets/runtime/lesson-v1.css itstep-pb-assets/runtime/lesson-v1.js
git commit -m "fix(runtime): keep lesson assets in sync"
git push origin main
```

Пример сообщения нужно заменить описанием конкретного изменения.
Подключение в HTML и состояние GitHub Pages описаны в [документе runtime](runtime.md).

## Подключение новых сабмодулей

Сначала создайте соответствующий репозиторий на GitHub и отправьте в него первый
коммит. Ниже примеры будущих репозиториев, а не ссылки на уже созданные:

```sh
git submodule add https://github.com/Zeyafix/itstep-pb-lesson-01-02.git lessons/itstep-pb-lesson-01-02
```

Внутри репозитория урока задания подключаются в пути `pa` и `hw`:

```sh
git submodule add https://github.com/Zeyafix/itstep-pb-pa-02.git pa
git submodule add https://github.com/Zeyafix/itstep-pb-hw-02.git hw
```

Для группы сначала проверьте, что её репозиторий **приватный**. Затем из корня
основного репозитория подключите его с `-f`, поскольку путь защищён `.gitignore`:

```sh
git submodule add -f git@github.com:Zeyafix/GROUP_ID.git groups/GROUP_ID
```

Заменяйте имена примеров реальными. Сохраняйте `.gitmodules` и ссылки на коммиты
сабмодулей в родительском репозитории. Не добавляйте обычные папки с работами
студентов с помощью `git add -f`.

## Изменение урока, заданий или группы

После загрузки сабмодуль обычно находится в состоянии detached HEAD.
Перед правками переключитесь внутри него на рабочую ветку и получите её обновления.
Сначала создайте и отправьте коммит в репозитории, где изменились файлы,
затем зафиксируйте новую ссылку на этот коммит в родительском репозитории.

Для вложенных заданий порядок такой: `pa` или `hw` → урок → `itstep-pb`.
Для группы: приватный репозиторий группы → `itstep-pb`.
Не фиксируйте в родительском репозитории коммит, который ещё не отправлен на GitHub.

## Зашифрованные материалы

`docs/syllabus.rar` предназначен только для преподавателей. Архив хранится
в публичном репозитории в зашифрованном виде; пароль и расшифрованное содержимое
в репозиторий не добавляются.
