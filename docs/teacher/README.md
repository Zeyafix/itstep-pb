# Работа преподавателя

Основной репозиторий `itstep-pb` публичный. План занятий находится в
[текущем плане курса](../current-roadmap.md); пока темы в нём не заполнены.
Зашифрованный архив [syllabus.rar](../syllabus.rar) предназначен только
для преподавателей и хранится в публичном репозитории в зашифрованном виде.

## Материалы для студентов

- Отправляйте ссылку на публичный репозиторий нужного урока, если студенту нужны
  заметки и HTML-теория. Проверки и эталонные решения в `checks` также публичны.
- Для выдачи только практических или домашних заданий отправляйте ссылку
  на соответствующий репозиторий `pa` или `hw`.
- В HTML-теории используется общий runtime из `itstep-pb-assets/runtime/`.
  Пока GitHub Pages не настроен, для относительных подключений нужна локальная
  копия основного репозитория с уроками и ассетами. Один скачанный HTML-файл
  без соседних ассетов не получит общие стили и обработчики.

Репозитории уроков и заданий пока не подключены. После их появления порядок
загрузки описан в [инструкции для разработчика](../development/repositories.md).

## Работы и история студентов

Для каждой группы используется отдельный приватный репозиторий, подключаемый
в `groups/GROUP_ID`. Доступ к нему есть только у уполномоченных участников.
В папке студента хранятся `summary.md`, `assessments/`, `hw/` и `pa/`.

Сохраняйте работы, оценки и историю обучения в приватном репозитории группы.
В публичные материалы, обсуждения и сообщения коммитов основного репозитория
данные студентов не включаются.
