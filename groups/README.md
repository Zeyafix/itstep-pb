# Группы

Здесь подключаются **приватные** Git-сабмодули групп. Сейчас они ещё не добавлены.
Работы студентов и история обучения хранятся только в приватных репозиториях.

Обычные файлы внутри этой папки, кроме данного `README.md`, исключены через
`.gitignore`. Группу подключают как сабмодуль после проверки приватности её
репозитория. Путь, URL и хеш коммита сабмодуля будут публичны.

Структура папок студента и команды подключения описаны в
[инструкции для разработчика](../docs/development/repositories.md).
